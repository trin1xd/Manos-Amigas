# Modelo de base de datos

El esquema incluido es deliberadamente inicial. Contiene las entidades mínimas necesarias para comenzar a conectar el prototipo actual con SQL Server:

- `Roles`
- `Usuarios`
- `Servicios`
- `Solicitudes`

Antes de implementar asignaciones, verificación de estudiantes, disponibilidad, familiares asociados, valoraciones o pagos, conviene definir sus reglas de negocio y luego ampliar el modelo.
